# Além da Maternidade — nuvem coletiva

Esta versão conecta a página ao Firebase Realtime Database do projeto `alem-da-maternidade`.

Funcionalidades:
- reflexões aleatórias revisadas;
- campo “Deixe uma palavra”;
- palavras compartilhadas entre todos os visitantes;
- nuvem atualizada em tempo real;
- palavras repetidas aparecem maiores;
- nenhuma identificação pessoal é solicitada;
- nomes das discentes e do professor coordenador;
- identidade visual mantida.

## Publicação
Substitua no repositório GitHub Pages:
- `index.html`
- `style.css`
- `script.js`
- `logo-projeto-original.jpg`

Faça commit na branch `main`. O endereço público permanece o mesmo.

## Segurança
O site depende das regras do Realtime Database já publicadas no Firebase. Não altere o banco para modo de teste.
