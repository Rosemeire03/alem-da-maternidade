# Além da Maternidade — página de reflexões

## Como publicar no GitHub Pages
1. Crie um repositório no GitHub (ex.: `alem-da-maternidade`).
2. Envie `index.html`, `style.css` e `script.js` para a raiz.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione `main` e `/ (root)` e salve.
6. Aguarde o endereço público, abra no celular e teste.
7. Use esse endereço para criar o QR Code do cartão.

As reflexões podem ser alteradas em `script.js`.
